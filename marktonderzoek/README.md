# Marktonderzoek loopbaan (los van de hoofdsite)

Een zelfstandige statische site in `marktonderzoek/`, zonder links naar of afhankelijkheden van de root-website.

- `index.html`: de pagina
- `assets/data.js`: alle data (organisaties, traineeships, kalender, salarissen, bronnen). Hier pas je inhoud aan.
- `assets/app.js`: filters, favorieten, actieplan-checklist en sollicitatietracker (opslag in `localStorage`, alleen in de eigen browser)
- `assets/style.css`: opmaak, met licht en donker thema

Openen: dubbelklik op `index.html`, of host de map (bijvoorbeeld GitHub Pages → `/marktonderzoek/`).
De pagina heeft `noindex`, zodat zoekmachines hem niet opnemen.

Peildatum van het onderzoek: 8 oktober 2026.
